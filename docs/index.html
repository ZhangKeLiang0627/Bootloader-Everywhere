1 连接设备

115200 8N1（固件固定）

波特率由固件写死 115200，不做协商 —— 选了别的值反而连不上。 从机地址对应固件里的 BL_DEVICE_ID，默认 1，只有地址匹配的板子才会应答。

2 固件

⇪

点击选择固件，或拖拽 .bin / .hex 文件到这里

固件需编译到 0x08004000 起始 —— Bootloader 占用前 16 KB， APP 的 IROM 起点与向量表偏移都要跟着对齐。 选 .hex 时本页会先解析：记录之间的空洞按 0xFF 填充， 并校验起始地址，编错地址会在这里直接报出来，不必等板子拒绝。

3 升级

0%

点「开始升级」会自动把设备唤回 Bootloader（无论它在跑 APP 还是已在 IAP）， 然后按 START → DATA → END 传输：每帧一应一答，板端会回读 Flash 重算 CRC32 供本页比对；出错时按板端给的地址续传，不会从头再来。
