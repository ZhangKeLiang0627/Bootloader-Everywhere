1 连接串口

浏览器会弹出串口选择框。需要 Chrome / Edge 89+， 且页面运行在 https:// 或 localhost 下。

2 选择固件

选编译出的 .bin（通常几 KB 到几百 KB）。 注意：不需要事先算好 CRC32 —— 整镜像校验由板子自己完成。
